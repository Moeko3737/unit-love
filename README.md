# 単位に恋して。

ZEN大学の新入生が、1年間の大学生活を疑似体験する乙女ゲーム風Webゲームです。
履修登録・情報収集・締切管理・単位認定試験・学外活動などを、擬人化キャラクターとの会話と選択を通して学べます。

## このゲームの目的

「知識を読んで終わる」のではなく、プレイヤーが次の行動を選べる状態になることを目指しています。

- 公式情報をどこで確認するか分かる
- 締切や試験を自分の予定と一緒に管理できる
- 参加しない選択も含め、情報を知った上で自分で決められる
- 困ったときに一人で抱えず、相談先を探せる
- 経験を振り返り、次の行動へつなげられる

## 起動方法

Macでは `ゲームを起動.command` をダブルクリックしてください。
ブラウザで `http://127.0.0.1:4173` が開きます。

ターミナルから起動する場合は、プロジェクトのフォルダで次を実行します。

```sh
npm start
```

ES Modulesを使用しているため、`index.html` を直接開かずローカルサーバー経由で起動してください。

## 操作

- 「はじめから」：新しい物語を開始
- 「つづきから」：自動保存された栞から再開
- 会話欄または右矢印：次へ
- 左矢印：一つ前へ戻る（能力値もその時点へ復元）
- 「成績」：現在の3能力と評価を確認
- 「サウンド」：音のON/OFFを保存
- 「エンディングアルバム」：到達した成長エンディングを確認

## シナリオ設計

全体はプロローグと4つのクォーターに分かれています。

| 区分 | 主なテーマ | プレイヤーの変化 |
| --- | --- | --- |
| 1Q | 履修・卒業要件・Slack・大学生活・レポート・試験 | まず確認すべき場所と基本行動を知る |
| 2Q | バイトとの両立・締切・地域活動・振り返り | 情報と予定を並べ、自分に合う選択をする |
| 3Q | 先を見た履修・国際交流・レポート内容・試験対応 | 説明を待たず、自分で確認して動く |
| 4Q | 総合的な予定管理・現在地・一年の記録 | 学んだ行動を組み合わせ、次年度へつなげる |

各章の最後には「攻略カード」が表示されます。会話中の要点を短くまとめ、実生活で行う「次の一歩」を一つ提示します。

12問の選択肢では、「01 自己管理」「02 情報活用」「03 大学生活」のいずれか一つが1〜3点伸びます。各能力を4問ずつ担当させ、A・B・Cのどこに高得点があるかも均等にして、選択位置だけでは正解を推測できないようにしています。最後の振り返りでは、自分が次に大切にしたい能力へ1点を加えます。

選択肢は、低い点を選んだプレイヤーを叱る構成ではありません。その時点の考えを受け止めたうえで、より安全・具体的に行動するための不足情報を会話で補います。

4Qの最後は、年間の3能力と総得点に応じて5種類へ分岐します。

- 全12問で3点を選んだ場合：「ぜんぶ、私の力になった」
- 全12問で1点を選んだ場合：「ぎりぎりでも、ここから」
- それ以外：最も高い能力に応じた「自分のペースで進む」「答えへたどり着く」「やってみたいを育てる」
- 最高点の能力が複数ある場合：その中から、最後の振り返りで選んだ能力を優先

到達済みの物語はブラウザ内のアルバムへ保存されます。

## 情報の扱い

大学制度は更新される可能性があるため、次の方針で管理します。

- 日付や持ち込み物など変更されやすい情報は、年度を明記する
- 科目ごとに異なる評価割合は「この科目では」と範囲を限定する
- 評価方法はシラバス、制度や手続きは最新の公式案内で確認するよう促す
- 分からない点はCC・AAなど大学の相談先につなげる

Q1-07・Q3-04の「候補日時は3つで、一つが最初に割り当てられる」流れと、Q1-08の「白紙30枚」などの受験準備は、プロジェクト制作者が学生向け案内で確認した2026年度情報を使用しています。更新時は `js/scenarios/shared.js`、該当章、内容検証テストを一緒に見直してください。

## 画面とUX

- スマートフォンを基準にしたモバイルファースト設計
- PCでは中央440pxのゲーム画面と左右の装飾を表示
- 360px以下でも選択肢・アルバムを一列表示に切り替え
- 通知、予定表、マイステップ、攻略カードを場面ごとに切り替え
- `aria-live`、読み上げ用ラベル、キーボード操作、`prefers-reduced-motion`に対応
- PNGとWebPを用意し、対応ブラウザではWebPを使用
- 次章の画像を先読みし、読み込み中も現在の立ち絵を保持
- 1年間の完結時は、一枚絵・物語タイトル・最終スコアを専用画面で表示

## 保存データ

保存にはブラウザの `localStorage` を使用します。

- `unitLoveBookmark`：栞、3能力、選択結果、戻る履歴
- `unitLoveSound`：サウンド設定
- `unitLoveEndingAlbum`：解放済みエンディング

保存が禁止されている環境でもゲームは継続し、画面を開いている間の栞を利用できます。保存データは別ブラウザ・別端末とは同期されません。

## テスト

外部テストライブラリは使用せず、Node.js標準の `node:test` と `assert` だけで実行します。

```sh
npm test
```

主な検証内容:

- 全シーンIDの一意性と必須項目
- 分岐先・章間遷移・全シーン到達性・無限ループの有無
- 均等に配置した12問と、最後の振り返り加点
- 5種類の成長エンディングから完結画面までの到達
- 選択肢に減点型の数値効果がないこと
- Q1-07／Q3-04とQ1-08の確認済み情報
- 栞の保存・再開・戻る・選び直し
- エンディングアルバムの保存と壊れたデータからの安全な復旧
- 通知・予定表・マイステップ・攻略カードの表示切替
- 画像の存在、WebP、先読み、読み込み競合

## 開発方針

- HTML / CSS / Vanilla JavaScriptのみ
- 外部ライブラリを追加しない
- 機能・章・テストを小さな単位でコミットする
- コミット前に `npm test` とPC／スマホ幅の表示確認を行う
- シナリオ変更では、伝える目的・重複・実生活での次の行動を確認する

画像素材の出典・利用条件は [docs/image-assets.md](docs/image-assets.md)、音源の差し替え方と不足素材は [docs/audio-assets.md](docs/audio-assets.md) に記載しています。
