# 画像素材の出典・ライセンス

本作品で使用している画像素材の出典区分と利用条件をまとめています。
PNG と WebP の両方があるものは、同じ画像の形式違いです。

## 出典一覧

| 対象 | 出典区分 | 利用条件・備考 |
| --- | --- | --- |
| `assets/images/characters/` | AI生成・編集（制作者が用意） | 本作品の登場人物用に生成・編集した画像です。各生成元・編集元に適用される規約と権利条件に従って使用します。 |
| `assets/images/backgrounds/` | AI生成・編集（制作者が用意） | 本作品の背景用に生成・編集した画像です。各生成元・編集元に適用される規約と権利条件に従って使用します。 |
| `assets/images/foregrounds/` | AI生成・編集（制作者が用意） | 本作品の演出用に生成・編集した画像です。各生成元・編集元に適用される規約と権利条件に従って使用します。 |
| `assets/images/endings/` | AI生成・編集（制作者が用意） | エンディング画面用に生成・編集した画像です。各生成元・編集元に適用される規約と権利条件に従って使用します。 |
| `assets/images/ogp/ogp-v6.png` / `ogp-v6.webp` | AI生成・編集（制作者が用意） | OGP用に制作した同一画像の形式違いです。SNS共有時のサムネイルとして使用します。 |
| `assets/images/ui/title-logo.png` / `title-logo.webp` | 自作・編集（本作品用） | 本作品のタイトル表示用に制作した画像です。 |
| 素材サイト由来の画像 | 該当なし | 現時点で、素材サイトから取得した画像をそのまま使用している箇所はありません。 |

## 審査時の確認事項

- この一覧に記載した画像は、本作品のために制作者が用意したものです。
- 外部素材を使用した場合は、取得元の利用規約・生成サービスの規約・元画像の権利条件を確認したうえで使用しています。
- 画像の再配布や、作品外での二次利用については、各生成元・編集元の規約を優先します。
- 画像そのもののクレジット表記が必要な素材を使用する場合は、このファイルに取得元と表記方法を追記します。
